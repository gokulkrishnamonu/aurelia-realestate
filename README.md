# Aurelia Developments — Premium Static Website Starter

This is a complete multi-page static website starter for a premium developer/construction brand.

## Included
- Home, About, Projects, Project Details
- Apartments, Villas, Commercial, Rentals
- Testimonials, Blogs, Blog Details
- Careers, Awards, Events, Handover Events
- Contact, Privacy Policy, Terms
- Shared CSS + responsive CSS + page-specific CSS
- Navigation, reveal animations, counters, project filtering, blog search, form demo handling
- Semantic HTML, accessible labels, responsive layout, SEO metadata, Open Graph metadata

## Important
1. Replace the sample brand "Aurelia" with your actual company name/logo.
2. Replace all Unsplash image URLs with your licensed project photography.
3. Replace sample contact details and project information.
4. Connect contact/career forms to your backend, CRM, email service or form provider.
5. Have the Privacy Policy and Terms reviewed by your legal counsel.
6. Add your real Google Business/profile links, social links, analytics and cookie consent if required.
7. For production, self-host fonts/images where practical and optimize images to WebP/AVIF.
